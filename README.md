# Linux for Beginners

A beginner-friendly guide to learning Linux — from how the OS works to practical command-line usage and scripting.

## Contents

| File | Topic |
|------|-------|
| [01-how-linux-works.md](01-how-linux-works.md) | Linux architecture, kernel, filesystem hierarchy, processes, permissions |
| [02-common-commands.md](02-common-commands.md) | Navigation, files, permissions, processes, networking, text processing, and more |
| [03-shell-scripting.md](03-shell-scripting.md) | Variables, conditionals, loops, functions, and practical scripting |

## Who is this for?

Anyone new to Linux who wants to:
- Understand how Linux works under the hood
- Learn essential command-line commands
- Write their first shell scripts
- Feel comfortable in a Linux terminal

## How to Use

Read the files in order — each builds on the previous. Every command includes examples you can try in your own terminal.
